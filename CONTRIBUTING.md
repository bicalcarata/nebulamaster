# Contributing to NebulaMaster

First of all, thank you for your interest in NebulaMaster.

This project exists because I wanted a simpler, more transparent way to process
astrophotography data. Every issue raised, bug reported, suggestion made and
pull request submitted helps improve the project for everyone.

## Before you start

Please open an Issue before starting work on large features or significant
architectural changes.

This helps avoid duplicated effort and allows us to discuss the best approach
before implementation begins.

Small bug fixes and documentation improvements generally do not require prior
discussion.

## Development philosophy

NebulaMaster aims to be:

- Predictable and deterministic.
- Easy to understand.
- Fast enough to process large astrophotography datasets.
- Cross-platform.
- Transparent in its processing.
- Focused on improving image presentation without modifying the original source
  data.

When proposing changes, please keep these principles in mind.

## Coding standards

Please:

- Follow the existing coding style.
- Prefer readability over cleverness.
- Keep functions focused and maintainable.
- Avoid unnecessary dependencies.
- Add comments where the reasoning is not immediately obvious.
- Ensure the project builds successfully before submitting changes.

## Pull Requests

Pull requests are welcome.

Please ensure that:

- The project builds successfully.
- Existing functionality is not broken.
- New functionality is appropriately documented.
- Pull requests remain focused on a single logical change where practical.

Constructive discussion is encouraged throughout the review process.

## Issues and feature requests

Bug reports should include:

- Operating system
- NebulaMaster version
- Steps to reproduce
- Expected behaviour
- Actual behaviour
- Screenshots where appropriate

Feature requests are welcome.

Please explain the problem you are trying to solve, not just the proposed
implementation.

## Astrophotography data

If sharing sample images for testing:

- Only share images that you have permission to distribute.
- RAW data, FITS, TIFF and PNG examples are all welcome.
- Please avoid sharing copyrighted datasets without permission.
