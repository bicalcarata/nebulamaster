Nebula Master Desktop Help

Nebula Master is a declarative image mastering tool. You work from an immutable source image, create ordered adjustments, preview the result, and export renders when you are ready.

Quick Start

  1. Choose File → New Project from Image….
  2. Select a TIFF, PNG, JPEG, or TIFF source image.
  3. Choose the parent folder where Nebula Master should create the project.
  4. Enter a project folder name when prompted.
  5. Nebula Master copies the source image into the new project and opens it.
Nebula Master creates a project folder for you. The source image becomes part of that project, and later preview and export files can be recreated at any time.

Open an Existing Project

  1. Choose File → Open Project….
  2. Select the project’s project.yaml file.
  3. The project, its adjustments, regions, and preview state will load.

Add and Edit Adjustments

  1. Click Add in the Adjustments panel.
  2. Choose the adjustment type you want to add.
  3. Select the new adjustment in the list.
  4. Use the right-hand inspector to change its settings.
  5. Use Affects to target Combined Image, Nebula, Stars, or Dark Dust.
  6. Use Apply in to keep the adjustment global or assign it to one or more regions.

Create an Adjustment from the Image

  1. Click Create Adjustment from Selection.
  2. Click a visible feature in the preview.
  3. Choose the adjustment type from the prompt.
  4. Nebula Master creates a normal adjustment at the end of the stack.

Regions

  1. Click Add Region.
  2. Click points in the preview to draw the polygon.
  3. Finish the region and then select it from the Regions list.
  4. Adjust edge softness if you want a feathered transition.
  5. Assign adjustments to that region from the inspector.

Preview Controls

  • Show Preview displays the current mastered result.
  • Show Source displays the source image.
  • Overlay shows semantic masks such as Stars, Nebula, or Dark Dust.
  • Before / After and Hold Previous help compare working changes.
  • Fit, 100%, −, and + control zoom.

Save Working Changes

The bottom panel lists unsaved semantic changes. Click Keep Change to write the edited project metadata back to disk. This saves the project state, not a rendered image file.

Export an Image

  1. Choose File → Export for Screen… or File → Export for Print….
  2. Select the output format and size.
  3. Choose the destination path.
  4. Nebula Master renders the current adjustment stack to that output.

Project Model

  • The project file is the source of truth.
  • Source images are immutable inputs.
  • Preview and export files are disposable render artefacts.
  • Adjustment order matters and remains editable.

Tips

  • Start with broad adjustments, then add targeted regional refinements.
  • Use semantic overlays to understand what Nebula Master is targeting.
  • If a result looks wrong, check the adjustment order and the selected target.
  • Use the Help button at any time to reopen this guide.
