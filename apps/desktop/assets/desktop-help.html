Nebula Master Desktop Help

Nebula Master is a declarative image mastering tool for nebula and dark-nebula images. You open or create a project, build an ordered stack of adjustments, preview the result, then export a render when you are ready. The source image stays untouched. The project metadata is the real saved work.

Think of Nebula Master as a project editor, not a destructive paint tool. Saving writes adjustment intent to the project. Preview and export images can be regenerated at any time.

What You See in the Main Window

  • Left panel: project details, source images, adjustments, regions.
  • Center panel: image preview, overlays, compare controls, zoom, sampling.
  • Right panel: settings for the currently selected adjustment and Dark Dust controls.
  • Bottom panel: unsaved semantic changes and the Keep Change button.

Create a New Project from an Image

  1. Choose File → New Project from Image….
  2. Select a TIFF, PNG, or JPEG source image.
  3. Choose the parent folder where Nebula Master should create the project.
  4. Enter the new project folder name when prompted.
  5. Nebula Master creates the project folder, copies the source image into it, and opens the project.

This is the normal first-time workflow. If you start with only an image and no existing project, Nebula Master will guide you through creating the project structure for that image.

Open an Existing Project

  1. Choose File → Open Project….
  2. Select the project’s project.yaml file.
  3. The project, adjustments, regions, semantic settings, and preview state will load.

The File menu also shows up to five recently opened projects across app sessions for quicker reopening.

If you already have unsaved changes, opening another project, creating a new one, or closing the app will ask whether you want to save, discard, or cancel first.

Basic Adjustment Workflow

  1. Click Add in the Adjustments section.
  2. Choose the adjustment type from the menu.
  3. Select the adjustment in the list on the left.
  4. Use the right-hand inspector to change its settings.
  5. Use the arrow buttons to move the adjustment earlier or later in the stack.
  6. Use duplicate, remove, or reset if you want to branch or refine the adjustment.

Adjustment order matters. Every adjustment works on the image state produced by the adjustments above it unless the rule explicitly uses the original image for selection.

Available Adjustment Types

  • Colour adjustments such as Red, Green, Blue, Cyan, Yellow.
  • Tonal adjustments such as Brightness, Black Point, Shadows, Levels, Saturation.
  • Texture and finish adjustments such as Colour Smoothness.
  • Creative palette adjustments such as Faux Hubble, Faux HOO, Foraxx-Inspired, Gold & Cyan, and Natural Bi-colour.
  • Dark Nebula Processing for dark dust and translucent obscuring structure.

Create an Adjustment from the Image

  1. Click Create Adjustment from Selection.
  2. Click a visible feature in the image preview.
  3. Choose the adjustment type from the prompt.
  4. Nebula Master creates a normal declarative adjustment at the end of the stack.

This is a fast way to start from a real image feature instead of building a new adjustment entirely by hand.

Pick Colour Points

Colour-based adjustments can use Pick ... Point to sample a visible colour directly from the preview. This selected point becomes the midpoint for that adjustment’s colour selection. Moving the amount slider then increases or reduces the influence around that sampled colour family.

Choose What an Adjustment Affects

Every adjustment can target one of the semantic image views shown in Affects:

  • Combined Image: affect everything.
  • Nebula: bias the adjustment towards nebula structure.
  • Stars: bias the adjustment towards stars only.
  • Dark Dust: bias the adjustment towards detected dark dust structure.

Dark Dust and Dark Nebula Processing

Nebula Master can generate a Dark Dust semantic mask and use it either as an overlay or as the target for normal adjustments.

  • Use Overlay to inspect the current Dark Dust or Stars view.
  • Use the collapsible Dark Dust Mask section in the right panel to tune the global dark-dust detection.
  • Use Dark Nebula Processing when you want a dedicated adjustment that reveals faint dark-nebula structure while preserving denser cores.

If a Dark Dust-targeted result looks wrong, check both the adjustment itself and the underlying Dark Dust Mask settings.

Regions

  1. Click Add in the Regions section.
  2. Click points in the preview to draw the polygon.
  3. Finish the shape and select it from the Regions list.
  4. Adjust softness if you want a feathered transition.
  5. Assign one or more adjustments to that region using Apply in.

Regions do not replace colour targeting. They are an extra spatial limit. You can combine region membership with Nebula, Stars, Dark Dust, and colour-point based selection.

Preview, Overlays, and Comparison

  • Show Preview displays the current mastered result.
  • Show Source displays the source image.
  • Overlay shows semantic views such as Off, Stars, Nebula, or Dark Dust.
  • Before / After compares current work to the saved state.
  • Hold Previous temporarily holds the previous rendered state for comparison.
  • Fit, 100%, −, and + control zoom.
  • The status area reports whether preview rendering is queued, active, ready, cancelled, or failed.

Palette Adjustments

Faux palette adjustments work like normal adjustments in the stack. The main amount control acts as a wet/dry mix between the incoming image and the fully mapped palette result. Some palettes also expose per-colour balance controls for finer tuning.

Save Working Changes

The bottom panel lists unsaved semantic changes such as added adjustments, changed targets, palette balance edits, reordered rules, and region updates. Click Keep Change to save those project metadata edits back to disk.

When nothing has changed yet, the bottom panel stays in a clean state rather than always implying that unsaved work exists.

Keep Change saves the project state. It does not export a finished render file.

Export an Image

  1. Choose File → Export for Screen… or File → Export for Print….
  2. Select the output format and size.
  3. Choose the destination path.
  4. Nebula Master renders the current adjustment stack through the shared renderer.

Screen export is for PNG, JPEG, or TIFF outputs sized for display. Print export adds physical dimensions and target DPI so you can generate output appropriate for printing.

A Good First Workflow

  1. Create or open a project.
  2. Inspect the image with overlays off.
  3. Check semantic overlays such as Stars or Dark Dust if needed.
  4. Add one broad adjustment, then preview the result.
  5. Add more targeted adjustments using colour points, semantic targets, or regions.
  6. Review the unsaved changes panel and click Keep Change.
  7. Export for screen or print when the project looks right.

Troubleshooting

  • If a result looks wrong, first check the selected adjustment target and adjustment order.
  • If a region-limited adjustment seems too broad, verify the assigned region and its softness.
  • If a Dark Dust-targeted result is odd, inspect the overlay and Dark Dust Mask settings before changing the adjustment further.
  • If you want to compare against the source, use Show Source or Before / After.
  • Use the Help button any time to reopen this guide.
